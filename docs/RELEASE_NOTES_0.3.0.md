# IDAX Shell 0.3.0 release notes

IDAX Shell 0.3.0 is the first complete public local-development preview. It
composes IDAX Core Runtime 0.3.0 with the Ledger and osTRIS modules behind a
single Spring Boot and React shell.

Highlights:

- local login and seeded development tenant;
- tenant, user, role and permission administration;
- saved compound filters and alert requests;
- distinct public frontend with collapsible and resizable navigation;
- integrated Ledger and osTRIS frontend extensions;
- Docker Compose and VS Code quick steps for Windows and Linux;
- local Swagger/OpenAPI access and readiness checks.

This is a development preview. Review the binary license, security guidance
and production deployment requirements before exposing the stack externally.
