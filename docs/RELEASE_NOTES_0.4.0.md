# IDAX Shell 0.4.0

This increment updates the public host to IDAX Core Runtime 0.4.0 and makes the
module boundary usable by independently deployed public products.

- expose Core effective permissions in the authenticated session;
- discover extensions from a validated manifest instead of product-specific
  routing branches;
- preserve limited-runtime bootstrap and SPA forwarding for public modules;
- retain the 0.3 local Docker/VS Code workflow and public administration UI.
